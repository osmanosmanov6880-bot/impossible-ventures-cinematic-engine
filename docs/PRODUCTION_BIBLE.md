# IMPOSSIBLE VENTURES · ПРОТОКОЛ НУЛЬ / THE SIGNAL
## Production bible — cinematic interactive engine v1

**Формат:** интерактивное веб-кино. **Длительность:** 4–6 минут по основному маршруту; до 10 минут для всех семи миров. **Сцен:** 18. **Финалов:** 2. **Ветки исследования:** 7 плюс секретное хранилище.

### Согласованные предположения
- Аудитория: владельцы брендов, маркетологи, креативные директора, B2B-партнёры, инвесторы.
- Цель: показать рекламную историю, которая не забирает внимание, а заслуживает его; предложить осмотреть платформу или изучить пилот.
- Главная идея: зритель сам определяет, будет ли будущее рекламы системой контроля или добровольной сетью историй.
- Язык: русский по умолчанию; английский и китайский как дополнительные.
- Первый релиз: доступное интерактивное произведение с программными matte-paintings и анимацией, **не притворяющееся фотореалистическими 8K-фотографиями**. Готовые кинопромпты позволяют заменить изображения впоследствии.
- Дорогая генерация видео и аудио: не требуется; бюджет внешних платных API — 0.

### Концепция: «Сигнал»
Сигнал зовёт зрителя внутрь ночного мегаполиса, где реклама превратилась в шум. Архив показывает семь дверей: Deep Code, Appeal 2049, AntiPersona, Brief Theatre, AdBiome, Museum of Attention, Attention Republic. Каждая дверь даёт осмысленный выбор: понять человека или управлять его вниманием. Сцены реагируют на решения, открывают осколки архива, меняют сюжетный маршрут и финал. Неожиданный поворот — «Сигнал не управляет человеком; он принимает форму его решений». В эпилоге пользователь может сохранить свой маршрут, начать заново или открыть код IMPOSSIBLE VENTURES.

### Драматургия
Пролог (пустота) → интрига (город потерял внимание) → исследование (архив) → открытие (семь альтернатив) → выборы и найденные документы → инверсия перспективы → секретный архив (при ≥3 осколках) → решающий выбор → два альтернативных финала → эпилог.

**Граф:** S00 → S01 → S02 → S03 → S04; затем S04 → (S05…S11) → S04. После исследования ≥2 различных миров: S04 → S12 → (S13 если ≥3 обнаруженных осколка; иначе S14) → S14 → [S15 | S16] → S17. Секретный S13 не обязателен. Повторное посещение мира изменяет выбор без удвоения счёта. Возврат разрешён, в финале — перезапуск.

### Визуальная библия · OBSIDIAN / COPPER / HUMAN SIGNAL
- **Материалы:** обсидиан, медь, мокрый асфальт, матовый известняк, стекло, белый музейный камень, органическая биолюминесценция.
- **Цвет:** основа #080D13; титры #F2F6F4; кольцо-сигнал медное #E4A26C; миры получают отдельный цвет: код — изумруд, суд — окисленная медь, зеркало — пепельно-розовый, театр — алый, биом — бирюза, музей — золото на известняке, республика — ледяной голубой.
- **Свет:** один читаемый ключевой свет 3/4, контровый тёплый свет, редкие практические источники, локальный объёмный туман, правильная глубина за счёт планов. Не делать все кадры сине-фиолетовыми.
- **Оптика:** эквивалент 28–35 мм для архитектуры, 50–85 мм для детали; виртуальные смены перспективы не более 2–3% масштаба и небольшого параллакса.
- **Кадр:** у каждого кадра свободная левая или нижняя треть под титр; главное действие не перекрыто текстом. Чередование общего плана, средней крупности, детали и тишины.
- **Мотив:** медное кольцо с белым ядром встречается в прологе, хабе, развязке и эпилоге.
- **Персонаж непрерывности:** Хранитель архива, 30–45 лет, стройный силуэт без видимого лица, длинный графитовый плащ с единственной узкой медной полосой слева. Не менять пропорции и одежду. В первой версии — силуэт/архитектура без детальной лицевой анимации.
- **Шрифт:** встроенный системный гротеск, заголовки широкие и короткие, технические метки моноширинные; никакой текста внутри изображения.
- **Движение:** CINEMATIC — лёгкий push-in + парение слоями и редкие частицы; BALANCED — умеренный масштаб и туман; LITE — статичный кадр. prefers-reduced-motion всегда выключает движение.
- **Звук:** синтезированный на устройстве Web Audio drone, смена гармонии и сигнал выбора. Тишина до жеста пользователя, кнопка включения/выключения и регулятор громкости. Титры передают тот же смысл.
- **Запреты:** фиктивные счётчики просмотров, fake CTR, нелицензированная музыка, резкий автозвук, агрессивный глитч, бессмысленное непрерывное вращение, перегруженные титры.

### Фактическое визуальное качество v1
18 самостоятельно созданных SVG-матовых сцен, viewBox 1600×900, формально векторные: «истинного» исходного растрового разрешения у них нет. Браузер рендерит их в текущем размере экрана; WebP/AVIF-кадры будущего релиза следует готовить отдельно в 1920×1080 для десктопа и мобильных кропах по композиции, не заявляя 8K без проверки. Каждой сцене соответствует промпт замены, путём конфигурации без переписывания логики.

### Механика взаимодействия
У каждой сюжетной сцены есть цель и управление. У семи миров по два решения; при выборе фиксируются только локальные сюжетные данные (без идентификации личности), а не рекламные события. Исследуемые объекты открывают фрагменты архива и показывают текстовую находку. Зритель может выбирать миры в произвольном порядке, менять ранее сделанное решение, изучать альтернативы, открывать тайную сцену, управлять звуком/качеством и сбрасывать локальное сохранение.

**Основное драматургическое правило:** каждая сцена меняет знание, эмоциональный темп или будущую ветку; ничто не добавлено ради количества эффектов.

Это художественное локальное приложение без реальных показов рекламы, оплаченных клиентов, статистически проверенных улучшений, платёжной интеграции или генеративного сервера ИИ.
