## Переходы и правила

- S00–S03: прямой маршрут; найденные заметки фиксируются локально без идентификации человека.
- S04: выбрать любой из S05–S11, вернуться в хаб и после не менее 2 разных миров перейти к S12. 7 дверей не фикция.
- S05–S11: два варианта решения для каждого мира и отдельная находка-осколок. Решение сохраняется в словаре, повторы не удваивают эффект. Отдельный «вернуться в хаб» доступен после выбора; осмотреть объект можно без ограничения по времени.
- S12 → S13 только при найденных ≥3 разных осколках, иначе S14. Секретная сцена необязательна для прохождения.
- S14 → S15 или S16 по явному принципу зрителя; оба → S17. Кнопка перезапуска доступна в финале.
- Пользовательские действия не выводят фиктивные рекламные CTR, лиды или продажи. Прогресс — только история.

## Чередование темпа

S00/01 — пустота → масштаб; S02 — деталь; S03/04 — величественная архитектура; семь миров — короткие камерные интерактивные эпизоды по выбору; S12 — визуальный поворот; S13 — тихое открытие; S14 — почти статичный моральный выбор; S15/16 — два противоположных общих плана; S17 — абсолютная простота.

## Заметка об исходниках

Список файлов **shot_00.svg ... shot_17.svg** является частью первого релиза и содержит сгенерированные программно SVG matte paintings, а не подлинные фотографии. Все сцены меняют визуальный файл через конфигурационный реестр; для фотореализма заменить только ассеты по prompts и не менять state engine.
